通用

启动与恢复

记住上次阅读来源
下次启动回到上次使用的在线来源或本地图书；来源不可用时使用可用入口。
记录并恢复阅读位置
由艾特阅读记录位置并尝试恢复；关闭后不清除已有记录，也不影响网站自己的进度同步。

关于设置保存

即时保存
每次修改会立即写入应用配置。保存失败时，当前控件会恢复到后端状态，并显示重试提示。

Preference 02

阅读与操作

这些偏好适用于支持相应功能的阅读页面。字体与排版请在阅读时打开“阅读 → 阅读样式”。

自动翻页

翻页间隔
自动翻页时每页停留的时间。已有自定义值会保留，不会因打开设置被覆盖。
在后台继续自动翻页
应用进入后台时仍尝试继续翻页；系统休眠或浏览器限速时可能暂停。

阅读操作

自动隐藏鼠标指针
在阅读正文且鼠标闲置时隐藏，移动后恢复。
启用阅读快捷键与遥控器
控制正文单键翻页与遥控按键；不影响应用菜单快捷键。
语音翻页
说「翻页」即翻页，仅阅读页生效，本机识别不上传。
翻页词
识别到该词立即翻页，2 秒内只触发一次；留空使用「翻页」。

快捷键参考

macOS 使用 Command，Windows/Linux 使用 Ctrl；正文单键由当前阅读来源决定。
